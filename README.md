# Beam Stream

A modern web-based screen recording application that allows users to capture, edit, and share their screen recordings with ease.

## Features

- Screen recording with audio support
- Real-time preview
- Simple and intuitive user interface
- Web-based (no installation required)
- Cross-platform compatibility

## Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, or Edge)
- WebRTC support enabled in your browser

### Usage

1. Open `index.html` in your web browser
2. Click the "Start Recording" button to begin capturing your screen
3. Use the controls to pause, resume, or stop recording
4. Save your recording when finished

## Development

This project is built using vanilla JavaScript and modern web APIs. The main technologies used are:

- HTML5
- CSS3
- JavaScript (ES6+)
- WebRTC API
- MediaRecorder API
